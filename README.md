# Витрина карточек товаров

## Посмотреть локально
1. Распакуйте архив ЦЕЛИКОМ (не открывайте index.html прямо внутри zip).
2. Откройте index.html из распакованной папки — рядом должна лежать папка img.
3. Картинки подгружаются автоматически.

## Выложить на GitHub Pages
1. Создайте репозиторий, например `portfolio`.
2. Загрузите в корень репозитория: index.html, README.md и папку img (можно перетащить всё содержимое распакованной папки сразу).
3. Settings → Pages → Branch: main → Save. Сайт появится по адресу username.github.io/portfolio/ через 1-2 минуты.

## Структура
- `img/case1` … `img/case5` — карточки кейсов, порядок показа = порядок номеров (1, 2, 3...).
- Контакт уже прописан: t.me/yan154rus (в футере index.html).
- Под каждым кейсом — блок "Для маркетплейсов": описание, SEO-ключи, заголовки ВБ и Озона. Правится прямо в index.html.
